School calendar

Choose a cycle day or No school for each date. Unknown dates stay unset. Dates do not rotate automatically. These local dates fill the Specials slot unless an optional external Specials feed overrides them.

Download school calendar (.ics) to import them into Google Calendar if useful.

Children and reminders

Local lunch calendar

Menus come from the JSON files in the server's lunch-calendars directory. Dates without a published menu stay unknown. No Google Calendar or URL is needed for local lunch dates. An optional external Lunch feed overrides local entries while configured.

School timezone

Optional external calendar subscriptions

Local school closures, specials, and lunch calendars work without Google Calendar or URLs. Add an external feed only when you want to subscribe to one; an external feed for a slot overrides that slot’s local calendar. To get a private URL, open that Google Calendar’s Settings → Integrate calendar → Secret address in iCal format. Anyone with a secret URL can read it, so keep it private.

Google Calendar feeds

Set a URL only for a slot where you want an external subscription. Each configured feed appears separately in the daily view and overrides that slot’s local entries. Anyone with a secret URL can read that calendar, so keep these URLs private. These URLs are only shown in /admin.
